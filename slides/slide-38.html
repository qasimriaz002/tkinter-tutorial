Firebase Realtime DB Connection with Python

Connecting a Python application to the Firebase Realtime Database allows you to perform CRUD (Create, Read, Update, Delete) operations in real-time. To achieve this securely, the official firebase-admin SDK is the best choice.

1. Prerequisites and Setup

Before writing the code, you need to set up your Firebase console and install the required Python package.

Step A: Install the Firebase Admin SDK

pip install firebase-admin

Step B: Download Service Account Credentials

  1. Go to the Firebase Console.
  2. Select your project.
  3. Click the gear icon (Project settings).
  4. Navigate to the Service accounts tab.
  5. Click Generate new private key. Rename the downloaded file to serviceAccountKey.json.

Step C: Get your Database URL

In the Firebase Console, go to Realtime Database and copy the database URL (e.g., https://your-database-name.firebaseio.com/).

2. Code Explanations

  • Initialization: credentials.Certificate("...") loads your private key. initialize_app establishes the session.
  • The Reference Model: Firebase is a JSON tree. db.reference('users') targets the specific path.
  • Methods:
    • .set(data): Overwrites data at the path.
    • .push(data): Adds data with a unique, auto-generated ID.
    • .get(): Pulls data as a Python dictionary.
    • .update(dict): Updates only specified keys without deleting others.
    • .child(key).set(value): Add Child: Adds a new specific child node at a defined path without generating a unique ID.
    • .delete(): Removes the node entirely.

3. GUI Interaction Logic

  • Path-Based Navigation: In the GUI, operations are performed by defining the "Path" (e.g., users/kashif089/City).
  • Auto vs Manual ID: "Push" generates a random key. "Set" at a specific child path uses a defined key.
  • Live Syncing: Every operation triggers a refresh to update the Visual Tree.

Python Path-Based Implementation

import firebase_admin from firebase_admin import credentials from firebase_admin import db # ========================================== # 1. INITIALIZATION & CONNECTION # ========================================== # Path to your downloaded service account JSON file cred = credentials.Certificate("serviceAccountKey.json") # Initialize the app with a service account, granting admin privileges firebase_admin.initialize_app(cred, { 'databaseURL': 'https://your-database-name.firebaseio.com/' }) # Get a reference to the root of your database or a specific node # We will use a 'users' node for this example root_ref = db.reference('/') users_ref = db.reference('users') # ========================================== # 2. CREATE OPERATIONS # ========================================== def create_user_with_custom_id(user_id, name, email, age): """ Creates or overwrites data at a specific path using set(). Use this when you already have a unique identifier (like a username or UUID). """ user_data = { 'name': name, 'email': email, 'age': age } # Navigates to 'users/user_id' and sets the data users_ref.child(user_id).set(user_data) print(f"Successfully created user with ID: {user_id}") def create_user_with_auto_id(name, email, age): """ Pushes data into the node using push(). Firebase automatically generates a unique, timestamp-based ID. """ user_data = { 'name': name, 'email': email, 'age': age } # Generates a unique key automatically new_user_ref = users_ref.push(user_data) print(f"Successfully auto-generated user with ID: {new_user_ref.key}") # ========================================== # 3. READ OPERATIONS # ========================================== def read_all_users(): """ Retrieves all data under the 'users' node using get(). """ all_users = users_ref.get() print("\n--- All Users ---") print(all_users) return all_users def read_specific_user(user_id): """ Retrieves data for a specific user ID. """ user_data = users_ref.child(user_id).get() print(f"\n--- Data for User {user_id} ---") print(user_data) return user_data # ========================================== # 4. UPDATE OPERATIONS # ========================================== def update_user_fields(user_id, updated_fields): """ Updates specific fields without overwriting the entire object using update(). 'updated_fields' should be a dictionary, e.g., {'age': 31, 'city': 'New York'} """ user_child_ref = users_ref.child(user_id) user_child_ref.update(updated_fields) print(f"Successfully updated fields for user: {user_id}") # ========================================== # 5. DELETE OPERATIONS # ========================================== def delete_user(user_id): """ Deletes a specific user node using delete(). """ users_ref.child(user_id).delete() print(f"Successfully deleted user: {user_id}") # ========================================== # EXECUTION / TESTING THE CRUD OPERATIONS # ========================================== if __name__ == "__main__": print("Starting Firebase Realtime Database Testing...\n") # 1. Testing CREATE # Create users with specific IDs create_user_with_custom_id("user_001", "Alice Smith", "alice@example.com", 28) create_user_with_custom_id("user_002", "Bob Jones", "bob@example.com", 34) # Create a user with a Firebase auto-generated ID create_user_with_auto_id("Charlie Brown", "charlie@example.com", 22) # 2. Testing READ read_all_users() read_specific_user("user_001") # 3. Testing UPDATE # Update Alice's age and add a new field 'status' update_user_fields("user_001", {"age": 29, "status": "active"}) # Verify the update read_specific_user("user_001") # 4. Testing DELETE # Delete Bob from the database delete_user("user_002") # Verify the deletion by reading all users again read_all_users()
